  documents in this folder are also public at `https://iyeok.org/docs/...`.

- Documents that need date tracking or author identification: `YYMMDD_HHMM_name_Shana.md` / `_Laude.md`
- Other documents: lowercase English with hyphens
- Every document is written English first, followed by the Korean original.
