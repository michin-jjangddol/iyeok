# 윤효점 화면 — 정효점의 수(6·7·8·9)를 쓰지 않는다 (261122_2014 LAUDE)

이전 문서: `docs/common/261122_1945_yarrow-yun-mapping_Laude.md` (보존). 판정 규칙은 같고, 윤효점의 화면 표현만 정리했다(JJDD: "정효의 6789는 표현할 필요 없다").

## 원칙

6·7·8·9는 최종 정시초를 넷씩 묶은 수, 곧 정효점의 표현이다. 윤효점은 각 차례의 소·다를 양·음으로 바꿔 효를 정하므로, 윤효점 화면에서는 이 수를 보이지 않는다.

- 전통 대응: 소 → 양(+), 다 → 음(−)
- 아이역 반전 대응: 소 → 음(−), 다 → 양(+)
- 판정: 셋 중 하나만 다르면 그 하나가 음양을 정한다(변하지 않는 효). 셋이 모두 같으면 변하는 효.
  - 셋이 모두 양 → 노양(변하는 양효), 양 둘·음 하나 → 소음(변하지 않는 음효), 음 둘·양 하나 → 소양(변하지 않는 양효), 셋이 모두 음 → 노음(변하는 음효)
- 예: 9·8·4 = 다·다·소, 반전 대응 → + + − → 양 둘·음 하나 → 혼자 다른 음이 정함 → 소음(少陰) · 변하지 않는 음효

## 수를 뺀 곳(윤효점일 때)

이번 효 머리말, 효 그리기, 효판, 완성 화면의 효 목록, 돌아보기 제목, ‘왜 이 효가 나왔나요?’의 이번 효, 효 판정표, 시초판 가운데 표시(‘정시초 4 × 7’ → ‘정시초 28’). ‘전통 대응으로 읽으면 7 · 소양’ 문장도 뺐다.

## 그대로 둔 것

- 괘 계산(본괘·변효·지괘)과 내부 값은 그대로다. 화면 표현만 바뀌었다.
- 가지 수(9·8·4, 21, 49 − 21 등)는 시초의 개수이므로 그대로 보인다.
- [다른 방식으로도 보기]의 정효점 비교에는 정효점이므로 수가 보인다.
- 변효 이름(초구·육이 등)은 전통 효 이름이라 그대로 두었다.
