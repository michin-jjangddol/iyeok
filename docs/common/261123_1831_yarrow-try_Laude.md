# 시초점 맛보기(바로 시작) — yarrow/try/ (261123_1831 LAUDE)

JJDD 직접 요청(SHANA 요청문). 동전점 맛보기처럼 시초로 실제 한 괘를 뽑고 본괘·지괘·괘사까지 본다.

## 주소와 진입

- 주소: `https://iyeok.org/yarrow/try/`. SHANA가 우선 검토하라고 한 경로를 그대로 썼다. 배우기 `learn/`, 설정 `options/`와 나란한 자리다.
- 진입: 시초점 메뉴의 기존 [바로 시작] 버튼을 이 화면으로 연결했다. 전에는 준비 안내 대화상자를 열었다. 메뉴 항목은 늘리지 않았다.
- 시초점 메뉴 요약에 효 읽기와 변효 기호를 더했다.
- '준비 중'이던 안내 글을 고쳤다.
  - 고친 곳: 시초점 메뉴, 설정 화면, 배우기 끝 안내, 홈 안내문
  - 홈 안내문은 영어로도 번역되므로 언어 사전 새 판 `261123_1831`을 만들었다.

## 흐름

1. 설정 확인
   - 덜어 내는 쪽, 효 읽기(방식·음양 대응), 변효 기호, 정시초 나누기를 요약해 보여 준다.
   - [시작] [설정] [배우기] 버튼이 있다.
2. 시작
   - 시초 50가지를 보여 준 뒤, 하나를 태시초로 따로 두고 정시초 49가지로 시작한다.
3. 차례마다 [움직이기 시작] → [멈춤]
   - 멈춘 순간의 위치가 나누는 자리로 바로 확정된다. 확인 버튼이나 다시 뽑기는 없다.
   - 움직이는 동안에는 개수를 숨긴다.
4. 자동 연출
   - 나누기 → 인시초 덜기 → 하늘 쪽 넷씩 → 땅 쪽 넷씩 → 윤시초·인시초 모으기 → 다시 모으기 순서로 보여 준다.
   - 한 장면은 0.7초다. 움직임 줄이기 설정이면 0.16초다.
   - 계산은 멈춘 순간 한 번만 하고, 연출은 그 결과를 보여 줄 뿐이다.
   - 연출 중에는 버튼이 비활성이다.
5. 세 차례가 끝나면 효를 보여 준다
   - 정효점: "이번 효: 8 · 소음(少陰)"
   - 윤효점: 수 없이 판정을 보여 준다.
   - 효판에 아래에서 위로 쌓는다.
6. [다음 효]
   - 태시초는 그대로 두고 49가지를 다시 모은다.
   - 여섯 효를 다 쌓으면 [괘 보기]가 나온다. 결과 화면으로 저절로 넘어가지 않는다.
7. 결과
   - 본괘·지괘와 그 기호를 보여 준다. 변효가 없으면 "본괘와 지괘가 같습니다"라고 쓰고 본괘만 그린다.
   - 변효 안내, 여섯 효 목록, 이번 괘의 방식을 보여 준다.
   - [과정 보기]에는 효마다 세 차례의 분할·모은 수·판정 설명과 적용 기준이 있다.
   - 괘사·효사도 보여 준다.

## 설정 공유와 고정

- 새 설정 체계를 만들지 않았다. 배우기와 같은 `iyeok.yarrow.settings.v1`을 같은 설정 모듈(`yarrow/261123_1036_settings_Laude.js`)로 읽는다.
- [시작]을 누를 때 설정 전체를 복사해 그 괘가 끝날 때까지 고정한다. 계산 기준과 표시 기준이 모두 포함된다.
  - 덜어 내는 쪽, 효 읽기, 음양 대응, 변효 기호, 나누기 시작 자리·빠르기
  - 다른 탭에서 설정을 바꿔도 진행 중인 효와 괘는 바뀌지 않는다.
- '진행 방식'(단계별·빠르게)은 배우기에서만 쓴다. 맛보기는 나눈 뒤의 과정을 늘 자동으로 보여 준다. 화면에 이 점을 안내했다.

## 계산 재사용

- 한 차례 계산: `yarrow/learn/261120_2155_procedure_Laude.js`의 `round`·`minLeft`·`maxLeft`·`lineOf`
- 효 판정·음양 대응·변효 기호·설명 글: `yarrow/learn/261123_1036_why-ko_Laude.js`의 `appliedValue`·`movingMark`·`headlineFor`·`lineLabel`·`readingText`·`criterionText`
  - 정시초 산수(`calcValue`)와 적용 효(`value`)를 따로 기록한다.
  - 기호는 판정된 효 종류에 붙인다.
- 본괘·지괘: `app/iching.js`
- 괘사: `assets/261123_1831_hexagram-texts_Laude.js`
  - 동전점의 괘사 불러오기·표시 코드를 그대로 옮긴 공용 모듈이다. 재시도, [다시 시도], '준비 중' 표시가 동전점과 같다.
  - 동전점은 바꾸지 않았다. 지금은 동전점 `app.js` 안에 같은 코드가 한 벌 더 있다. 나중에 동전점이 이 모듈을 쓰게 하면 한 곳에서 관리할 수 있다.
- 시초판 그림은 배우기와 같은 모양이다. 화면 흐름이 달라서 그리는 코드는 맛보기 안에 따로 있다. 계산과는 무관하다.

## 중단과 다시 시작

- [처음부터]를 누르면 확인 창이 뜬다.
  - 취소하면 그대로 이어진다.
  - 확인하면 설정 확인 화면으로 돌아간다.
  - 남은 연출 타이머는 처음부터 이후의 새 괘를 건드리지 않는다. 처음부터와 새 괘마다 바뀌는 토큰으로 막는다.
- 화면이 숨겨질 때
  - 움직이는 중이었다면 나누지 않은 상태로 되돌린다. 임의로 나누지 않는다.
  - 연출 중이었다면 남은 연출을 바로 끝낸다. 이미 정해진 결과라 다시 계산하지 않는다.
- 진행은 저장하지 않는다. 새로고침이나 페이지 이동을 하면 초기화되며, 화면에 이 점을 안내했다.
- 멈추는 순간을 사람이 고르는 체험이라, 완전 무작위나 전통 시초법의 확률을 보장하지 않는다고 화면에 적었다.
