# assets/images

This folder holds the illustrations shown on the homepage and app screens.

## Files to add

- Illustrations such as ink-wash paintings (e.g. the wind-and-earth image for Hexagram 20, Guan)
- The shapes of the 64 hexagrams are drawn on screen from the data in `data/`, not stored as images.
- Images used only in design documents go in `docs/`, not here.

## Naming

- Lowercase English with hyphens: `wind-earth.webp`
- Convert to `.webp` for the web; aim for about 200KB per image
- Group into subfolders as images grow, e.g. `illustrations/`
