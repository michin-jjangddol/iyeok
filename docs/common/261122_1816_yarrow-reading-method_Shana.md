# Yarrow reading methods

JJDD defines Jeong/Yun as iYeok learning terms, not established historical school names. Jeong stalks are retained groups of four; Yun stalks are each pile's remainders (1–4, including four). The human stalk is removed each round and is distinct from the initial reserved stalk. Jeong reads the final groups; Yun reads the three removed totals. Both explain the same unchanged calculation. Default: Jeong. Saved per device; the reading method is fixed at a new lesson, while existing pace behavior remains. The alternate view does not change settings or records. No speech/audio exists in the current lesson, so only displayed scripts are updated. No new historical-source verification is claimed.

# 정효점·윤효점

JJDD가 정한 아이역 학습용 명칭이며 전통 유파 이름이 아닙니다. 정시초는 네 개씩 센 묶음, 윤시초는 각 무더기의 나머지 1~4개입니다. 나머지가 4개여도 윤시초입니다. 매 차례의 사람시초는 처음 따로 둔 하나와 구분합니다. 정효점은 최종 정시초 묶음 수, 윤효점은 세 차례에 모은 윤시초·사람시초의 소·다로 같은 효를 읽습니다. 계산·확률은 바뀌지 않습니다. 기본값 정효점, 기기 저장, 새 배우기 시작 시 고정입니다. 다른 방식 보기는 설정과 기록을 바꾸지 않습니다. 기존 진행 속도 적용 규칙은 유지합니다. 현 배우기에는 음성 재생이 없어 화면 대본만 갱신했습니다. 전통 문헌을 새로 대조했다고 주장하지 않습니다.
